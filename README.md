# NewsKarnataka Platform

AI-powered news aggregation platform for Karnataka news.

## Deployed Applications

- **Website:** https://newskarnataka-website.vercel.app
- **Admin Console:** https://newskarnataka-console.vercel.app

## Tech Stack

- Next.js 14 (Frontend)
- React + Vite (Admin Console)
- Strapi CMS (Backend)
- PostgreSQL (Database)
- Vercel (Hosting)

## Deployment

Automated CI/CD via GitHub Actions and Vercel.
