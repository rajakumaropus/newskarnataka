❌ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Error: "STRAPI_API_TOKEN not found"
  → Set environment variable first
  → $env:STRAPI_API_TOKEN = "your-token"
  → Then run script again

Error: "Connection refused"
  → Verify Strapi running at http://103.191.208.235:1337
  → Wait a few seconds if just started

Error: "Unique constraint violation"
  → Normal if script ran twice
  → Script handles duplicates gracefully
  → Safe to continue

Collections don't exist in Strapi
  → Create manually in Strapi Admin UI
  → Then run script again to seed data

Still having issues?
