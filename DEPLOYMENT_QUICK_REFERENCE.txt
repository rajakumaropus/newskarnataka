TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Error: permission denied
  → Check user is "news", contact Team C for escalation

Error: extension uuid-ossp does not exist
  → Run: CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

Error: relation "categories" does not exist
  → Tables must be created in order, run full script again

Error: duplicate key value
  → Schema already partially created
  → Backup, DROP SCHEMA public CASCADE, CREATE SCHEMA public, rerun

Error: timeout
  → Script is large (10,000+ lines), increase pgAdmin timeout settings
