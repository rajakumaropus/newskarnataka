## 💡 DISCUSSION STARTERS

### From PROJECT_DISCUSSION_SUMMARY

**Discussion Point 1: Location-Based Hierarchy**
- How confident are we in the location-based model?
- Should Bangalore users ever see non-Bangalore news?
- What's the algorithm for tier assignment?
- How do we handle critical national news?

**Discussion Point 2: Groq Integration**
- Is <100ms validation realistic?
- What's the fallback if Groq API goes down?
- How do we train the model for our use case?
- Should we have Claude backup for critical stories?

**Discussion Point 3: 8-Week Timeline**
- Can we realistically hire & onboard 28 people in Week -1?
- What happens if we miss Week 3 milestones?
- How do we prioritize features if we get behind?
- Should we have contingency plans?

**Discussion Point 4: Revenue Model**
- Why 50% ads / 30% real estate / 20% subs?
- Is real estate advertising sustainable long-term?
- Should we prioritize profitability or growth?
- When do we raise Series A?

### From FULL_PROJECT_COMPARISON

**Discussion Point 5: Phase Sequencing**
- Why Phase 1 first instead of both simultaneously?
- Should we launch Phase 2 simultaneously despite risks?
- What if Phase 1 fails - does Phase 2 still make sense?

**Discussion Point 6: Technology Choices**
- Flutter + React (why not React Native for all)?
- PostgreSQL + Elasticsearch (why not MongoDB)?
- Groq + Claude (why this specific combination)?

**Discussion Point 7: Team Structure**
- 28 people for 8 weeks - is this right-sized?
- Should Phase 1 and 2 teams overlap?
- What's the critical path / blocking dependencies?

### From EXECUTIVE_SUMMARY

**Discussion Point 8: Break-Even Timeline**
- 6-7 months break-even is optimistic - what if it's 12 months?
- What happens to burn rate if user acquisition is slow?
- Should we have contingency funding?

**Discussion Point 9: Market Competition**
- Who are our actual competitors?
- Can competitors replicate our model in 6 months?
- What's our moat beyond first-mover advantage?

**Discussion Point 10: Expansion Strategy**
- Mysore/Mangalore in Month 4 - is this too early?
- When do we expand nationally?
- What's the playbook for new cities?
